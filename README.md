# TaskFlow

TaskFlow is a task management dashboard built using React and Vite. It helps users organize and track their tasks.

## Requirements
- Node.js
- npm

## Installation
```bash
npm install
```

## Run the application
```bash
npm run dev
```

Open the local URL shown in your terminal.

## Build
```bash
npm run build
```

## Preview the production build
```bash
npm run preview
```

## Run tests
```bash
npm test
```

## Technologies Used
- React
- Vite
- JavaScript
- CSS
